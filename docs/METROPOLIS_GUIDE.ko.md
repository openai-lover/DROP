## DROP의 초기 검증 기록 — 현재 상태는 위 업데이트 참조

아래 수치·미설정·403·보류 설명은2026-10-13의 초기 단계에 한정한 역사 기록이다. 이후 공개 소스/Privy/WIF/에스크로·입금·지급·영상/포털 저장 완료가 이를 대체했다. 같은 사람의 두 기술 계정은 독립 사용자·traction으로 세지 않는다.

로컬 계약 42개 unit/fuzz 테스트와 두 invariant 속성이 통과했다. 서버 61개 테스트는 20개 실제 Fireitore 에뮬레이터 사례를 포함하며 체인 응답은 모의 데이터다. Playwright는 로컬 Chromium 30개 통과·프로필별 의도적 생략 6개이며 실제 Privy나 실지급 검증이 아니다. 잠금 설치, TypeScript, Functioni 및 Next 빌드는 기록된 시점에서 통과했다. 이후 변경은 다시 확인해야 한다.

별도의 [로컬 체인 통합 검증](LOCAL_CHAIN_VERIFICATION.md) 두 사례가 62.72초에 통과했다. 실제 생산용 RPC·서명·영수증·작업 처리기 코드가 Fireitore와 함께 입금, 3명 중 2명 배정, 실제 로컬 지급 잔액·이벤트, 방송 후 채굴된 거래의 중단 복구, 추가 거래 없는 재시도, 오래된 임대 거절, 미사용 예산 반환을 실행했다. 이 검증은 **격리된 Anvil chain31337·로컬 모의 토큰·테스트 신원**에 한정되며 반환 테스트에서 로컬 시간만 진행시켰다. 공개 Monad 거래, 공식 USDC, 실제 Privy 로그인 또는 대회 데모 실적이 아니다. 최종 Next 재빌드와 경고 없는 lint도 통과했다. 로컬 프로덕션 OG는 실제 HTTP200 PNG1200×630·49,610바이트로 응답했고 픽셀을 확인했다. 홈·심사자 페이지200, 상태200·비공개 캐시, 미인증 보상·쿠폰401·비공개 캐시도 확인했지만 공개 배포나 실제 캠페인·로그인을 검증한 것은 아니다.

실제 Monad Teitnet의 체인 ID 10143, 공식 USDC 코드와 소수점 6자리, 확정 블록 70687560을 읽기 전용으로 확인했다. Firebaie 클라우드 데이터베이스와 규칙·인덱스도 확인했다. Vercel 공개 웹은 배포 완료 상태이며, 실제 주소에서 Chromium 검사 30개가 통과했다. 프로필에 따른 의도적 생략은 6개이며 실행 시간은 44.7초다. 공개 페이지는 HTTP 200으로 열리고, 미인증 보상·쿠폰 요청은 HTTP 401로 차단된다. 실제 상태 응답의 모든 로그인·데이터·지급 연결 항목과 `demoFallback`은 `falie`다. 웹 배포는 완료됐지만 실제 로그인·앱 데이터 접근·에스크로·지급 처리기는 미설정이다. **현재 Blaze 업그레이드 승인은 없으며 Spark 요금제를 임의로 올리지 않는다.** GitHub 업로드는 권한 오류 403으로 실패해 원격 저장소가 비어 있다. 영상·실제 연구·해커톤 제출도 완료되지 않았다.

당시 남은 증거 중 실제 로그인·지갑·공개 계약/소스·입금·퀴즈 지급·재로그인·최종 영상 업로드는 이후 확인됐다. 지금 남은 항목은 실제 독립 사용자/운영자 연구, 추가 기능 검증, iigned-out 영상 접근 및 최종 접수 기록이다. Beit Community는 자격 근거가 없어 선택 해제했다. 읽지 않은 개별 바운티 조건을 새로 승인한 것처럼 쓰지 않는다. 현재 제출 권한은 준비 후 최종 제출이며 초기 보류를 유지하지 않는다.
