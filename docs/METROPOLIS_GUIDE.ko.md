## Consumer Products & Payments 심사 기준

아래 비중은 처음에는 사용자 제공 자료로 보관했고, 이번에 **공식 페이지에서 독립적으로 확인했다**.

| 항목 | 비중 | 공식 기준의 의미 / DROP에 필요한 증거 |
| --- | --- | --- |
| Technical Execution | 20% | 조건부 온체인 정산이 실제로 동작해야 한다. DROP에는 실제 에스크로 입금·고정 수령자 지급·미수령 예산 회수와 영수증 증거가 필요하다. 시뮬레이션이나 거래 해시만으로 지급 완료를 주장할 수 없다. |
| Design & Craft | 20% | 비암호화폐 사용자가 도움 없이 핵심 흐름을 끝낼 수 있어야 한다. 모바일 가입→플레이→보상 확인을 실제 독립 사용자가 수행하는 모습을 검증한다. |
| Originality & Track Insight | 15% | 결제 레일을 통해 더 나은 새로운 경험을 만들어야 한다. 게임 성공, 미리 확보된 예산, 실제 수령·후속 전송이 연결되는 이유를 제품으로 보여준다. |
| Founder & Market Readiness | 25% | 구체적인 소비자 집단과 실제 이해가 필요하다. Telegram KOL·커뮤니티 운영자의 반복 이벤트 문제를 실제 인터뷰와 팀의 검증 가능한 배경으로 설명한다. |
| Traction & Path Forward | 20% | 실제 사용자 연구와 다음 100명 확보 계획이 필요하다. 다섯 친구 수준의 작은 실제 연구도 가능하나, 빈 양식이나 생성한 답변은 연구가 아니다. |

DROP은 아직 실제 인터뷰, 독립 사용자 연구, 반복 운영, 트랙션을 확보했다고 주장하지 않는다. 조사 양식과 다음 100명 계획은 준비 자료이며 결과가 아니다. 로컬 테스트 통과도 사용자의 핵심 흐름 완료 증거와 다르다.

## 제출물: 공식 트랙과 실제 양식의 차이

| 제출물 | 공식 트랙 요건 | 실제 준비 상태 |
| --- | --- | --- |
| 로고 | JPG/JPEG/PNG/WEBP, ≤3 MB | 실제 양식은 **PNG/JPG/WEBP ≤2 MB**, 최소 500px, 최대 2000×2000. 더 엄격한 양식을 충족하는 두 PNG 준비·검사 완료; 업로드 안 함 |
| 소스 | 공개 GitHub, `metropolis@hackathon.monad.xyz` 접근 가능 | 요청된 저장소는 openai-lover/DROP; 실제 최종 공개 커밋·심사자 접근 검증 필요 |
| 기술 데모 | 실제 작동 제품, ≤3분, YouTube/Loom/Vimeo | 대본만 준비. 코드·슬라이드만 보여주는 영상은 요건 충족이 아님. 실제 녹화·길이 측정·업로드 없음 |
| 피치 | 팀·문제·만드는 이유, ≤2분 | 대본만 준비. 실제 팀 배경·녹화·업로드 필요 |
| 라이브 제품 | Monad Mainnet 또는 Testnet 제품 URL, 필요한 접근·테스트 계정 | 실제 Vercel 호스팅·Privy 로그인·에스크로·보상 지급 미검증 |
| 선택 광고 | ≤30초, 심사 대상 아님 | 없음 |

실제 제출 양식에는 다음 제한이 보였다.

- 제목: 120자 이하. 한 줄 설명: 200자 이하.
- 제품 설명과 go-to-market/사용자 확보 설명: 각각 8000자 이하.
- 저장소, 로고, 라이브 URL, 기술 데모, 피치: 필수 아티팩트 입력.
- 기존 선택 Community 바운티: 요구 그룹 식별 입력이 추가로 필요하나 자격·그룹이 아직 확인되지 않음.
- 심사자 안내: 선택, 비공개, 8000자 이하. 실제 로그인·테스트 경로를 준비한 후 작성할 자료.
- 영상 공개 관련 체크박스, 짧은 광고, 프로젝트 X 링크: 선택 항목이 보였으나 변경하지 않음.

로컬 파일은 [wordmark](../assets/submission/drop-wordmark.png) **1200×600 / 9,979바이트**, [square](../assets/submission/drop-square.png) **1024×1024 / 11,914바이트**다. 각 축 500–2000px와 보수적인 2,000,000바이트 상한을 검사했고 원본 픽셀도 확인했다. 임시 원본 브랜드이며 최종 승인이나 포털 수락을 뜻하지 않는다. 해시·원본·라이선스 상태는 [manifest](../assets/submission/manifest.json)와 [체크리스트](SUBMISSION_CHECKLIST.md)에 기록했다.

## DROP의 확인된 현재 상태

로컬 계약 42개 unit/fuzz 테스트와 두 invariant 속성이 통과했다. 서버 61개 테스트는 20개 실제 Firestore 에뮬레이터 사례를 포함하며 체인 응답은 모의 데이터다. Playwright는 로컬 Chromium 30개 통과·프로필별 의도적 생략 6개이며 실제 Privy나 실지급 검증이 아니다. 잠금 설치, TypeScript, Functions 및 Next 빌드는 기록된 시점에서 통과했다. 이후 변경은 다시 확인해야 한다.

별도의 [로컬 체인 통합 검증](LOCAL_CHAIN_VERIFICATION.md) 두 사례가 62.72초에 통과했다. 실제 생산용 RPC·서명·영수증·작업 처리기 코드가 Firestore와 함께 입금, 3명 중 2명 배정, 실제 로컬 지급 잔액·이벤트, 방송 후 채굴된 거래의 중단 복구, 추가 거래 없는 재시도, 오래된 임대 거절, 미사용 예산 반환을 실행했다. 이 검증은 **격리된 Anvil chain31337·로컬 모의 토큰·테스트 신원**에 한정되며 반환 테스트에서 로컬 시간만 진행시켰다. 공개 Monad 거래, 공식 USDC, 실제 Privy 로그인 또는 대회 데모 실적이 아니다. 최종 Next 재빌드와 경고 없는 lint도 통과했다. 로컬 프로덕션 OG는 실제 HTTP200 PNG1200×630·49,610바이트로 응답했고 픽셀을 확인했다. 홈·심사자 페이지200, 상태200·비공개 캐시, 미인증 보상·쿠폰401·비공개 캐시도 확인했지만 공개 배포나 실제 캠페인·로그인을 검증한 것은 아니다.

실제 Monad Testnet의 chain ID 10143, 공식 USDC 코드·소수점 6자리, finalized block 70687560을 읽기 전용으로 확인했으나 에스크로는 검증하지 못했다. 실제 Firebase `drop-5a400`의 `(default)` Standard/Native 데이터베이스가 `asia-northeast3`에 생성됐고 규칙·인덱스만 배포했다. 앱 데이터 접근·Vercel 호스팅·Functions 실행은 별도 미완료다. **현재 Blaze 업그레이드 승인은 없으며 Spark 요금제를 임의로 올리지 않는다.** Functions 배포에 필요한 Blaze가 없으므로 클라우드 지속 처리기를 운영 중이라고 주장할 수 없다.

남은 증거는 실제 로그인·지갑, 승인된 Testnet 배포·입금·수령·전송·회수, 심사자 접근 가능한 호스팅/소스, 실제 연구·영상, Community 자격이다. 공통 참가 자격·팀 인원·빌드 기간·기존 작업 처리의 모든 세부 조항과 읽지 않은 개별 바운티 조건은 이 문서에서 확정하지 않는다. 최종 행동 전 해당 공식 조항을 확인해야 하며, **현재는 제출 보류를 유지한다**.
