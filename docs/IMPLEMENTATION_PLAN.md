3. Connect mobile catch and quiz play to real eligibility and payout states, with a clearly separate anonymous practice.
4. Connect creator budget deposit, frozen rules, participation/payout monitoring and expiry refunds.
5. Connect persistent rewards, authenticated coupon disclosure and explicitly approved sponsored USDC transfer.
6. Verify type/lint/unit/build/contract/browser behavior; resolve observed gaps before claiming completion.
7. Publish reviewed source to the requested GitHub repository. Deploy live testnet only with approved credentials and budget.
8. Produce submission logo, real product/demo/pitch artifacts and real user evidence. Missing external credentials, interviews and videos remain incomplete until independently evidenced.

No P1/P2 work before P0 passes. No invented partners, traction, balances, receipts or transaction hashes.
